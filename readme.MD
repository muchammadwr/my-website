# Muchammad Wildan Alkautsar — Data Scientist & Data Analyst Portfolio

A lightweight, responsive, accessible personal portfolio built exclusively with semantic **HTML5**, **CSS3**, and **Vanilla JavaScript (ES6+)**—zero external libraries, frameworks, or build steps.

## How to Run
1. Save the files into the `portfolio/` directory structure (`index.html`, `css/`, `js/`, `assets/`).
2. Open `index.html` directly in any modern browser, or run a local static server:
   - **VS Code:** Right-click `index.html` → *Open with Live Server*
   - **Python:** `python -m http.server 8000` and visit `http://localhost:8000`

## Customization Checklist
- **Portrait Photo:** Place your photo at `assets/images/profile.jpg` (an automatic SVG fallback renders until added).
- **CV / Resume:** Place your PDF resume at `assets/cv/wildan-cv.pdf`.
- **Contact Links:** Update your exact email address, GitHub URL, and LinkedIn URL in `index.html` and `js/projects.js`.
- **Projects & Case Studies:** Edit the `PROJECTS_DATA` array in `js/projects.js` to add repository links, live Streamlit/Looker Studio demos, or custom screenshots.
- **Experience, Stats & Credentials:** Replace the bracketed `[Placeholder]` entries in `index.html` (Sections C, E, and H) with your verified dates, institutions, and credential links.
